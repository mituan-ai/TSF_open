# IndPenSim 场景说明

本文档只记录当前仓库采用的 `IndPenSim` 离线青霉素软测量协议。场景说明用于解释批次划分和评测域，不作为输入变量，也不生成场景专属变量 embedding。

## 任务口径

- 任务：离线青霉素浓度 `penicillin_offline` 软测量。
- 基础时间步：`12` 分钟。
- 样本：只在有离线青霉素化验值的时刻取样。
- 窗口：向前取 `120` 个在线过程时间步，窗口包含当前化验时刻。
- 输入边界：不使用拉曼、不使用 `penicillin_online`、不使用任何离线化验辅助量。

## 边界

- `same_family_recipe_030` 是测试批次，不参与训练。
- APC 批次的重点是控制策略变化，而不是模型看到了拉曼；当前输入不包含拉曼谱。
- 故障说明只用于解释评测域，不应让 LLM 生成测试场景专属的变量语义。
- 每批前两个离线标签点 `1h`、`12h` 因窗口不足跳过，`24h` 起可用于建样本。
